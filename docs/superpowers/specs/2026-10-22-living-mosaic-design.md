# Living mosaic discovery

The user approved the preceding product proposal and requested implementation, push and merge. Preserve the white/pastel pixel identity and the small controls. Make discovery spatial: the actual papers, photos and shared pixels remain visible at every distance, Wander lands among real stored originals, and build-on starts beside the original.

## Behavior

- Remove the distant generic icon map and screen-sized title tiles. Retain physical positions, paper colors, actual body text, photos, image frames and explicit build-on threads at all zoom levels. Use normal browser compositing; this pilot does not need a new rendering engine or database migration.
- Start the existing campus patch at an overview distance, preserving its true center. Whole/Wander/Up close still zoom around the same point; Explore frames all occupied content.
- Wander keeps the existing unseen-original random selection. It focuses an actual neighborhood and opens a compact anchored preview, with Read, Build on and Next actions. Canvas clicks use the same preview. Search citations keep their full reader and return behavior.
- Build-on reuses the existing text/image/link composer, anchored beside the source on desktop and above the dock on phones. Positioning/confirmation, uploads, authorship and explicit parent IDs continue through the existing pipeline. A saved child returns to the spatial preview. Draft recovery and source withdrawal remain safe.
- Newly received originals or versions receive a brief bounded highlight; initial starters do not animate. Real cursors and peer strokes keep their existing behavior.

## Constraints

No fabricated users, memories, activity or relationships. No movement of other people's originals. No new motion dependency. Readable fields, visible keyboard focus, touch targets and reduced motion remain supported. RAG and backend authorization remain unchanged.

## Evidence

Test neighborhood/overlay geometry at desktop, phone and signed extreme coordinates; exclude distant outliers. Verify actual photo/text rendering at far zoom, repeatable unseen wandering, anchored composing, draft recovery, search return and a real two-visitor publish/upload/build-on flow. Run unit tests, type checking, production build, desktop/mobile UI verification, an independent review, CI and public deployment checks.
