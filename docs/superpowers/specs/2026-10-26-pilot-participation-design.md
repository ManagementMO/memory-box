# Pilot participation and effort protection

Implement the user's pasted pilot review within the existing continuous white/pastel pixel world. Preserve authored content, spatial positions, guest ownership, live collaboration and the two arrival assignments.

## Deliverables

- Persist unfinished text/link drafts, photo captions/local image files and up to 144 brush cells locally. Recovery is explicit, never publication. Retain source links, stable save IDs and authored placement. Isolate world/epoch/guest and concurrent tabs. Accepted saves and deliberate discard remove their own recovery only. Storage denial leaves work usable in the current tab with an honest warning.
- Help a newcomer join or start a real build through current Together tools. Optional concrete starters populate an unpublished draft; never masquerade as real community activity. Do not replace a draft that contains effort.
- Save public places locally and compare real nearby originals/pixels with the last explicitly acknowledged visit. Initial history is not new activity. No cached removed story text or fabricated notifications.
- Let distant artwork/material silhouettes lead; show words only when they can be read, preserve accessible original names and close-up content.
- Add an operator-only browser review queue using existing authorization and moderation transactions, plus denied/loading/error states. Hide/restore changes source visibility; a separate service-only, idempotent transaction resolves or dismisses a report with a private append-only receipt. Recheck trusted permissions and preserve Auth-deletion lock ordering.
- Add truthful retrieval relevance and bounded pilot performance harnesses. Conditional snapshots validate full visible content so index-only changes cannot be hidden by an unchanged world revision.

## Constraints

Use existing dependencies and pixel tokens. Keep readable controls and touch targets on desktop/mobile; no decorative slogans, modal onboarding, fake visitors, published seed prompts, unsolicited outreach or analytics events. Change no experiment settings, allocations or metric definitions. QA uses preview/non-enrolled contexts. Optional account recovery and broad spatial paging need separate infrastructure evidence; do not invent production credentials or claim scalability/adoption from fixtures.

## Verification

Focused regression tests cover recovery, corrupt/blocked storage, session/world boundaries, accepted-save cleanup, multi-tab preservation, real change baselines, conditional response freshness, operator authorization and deterministic evaluation correctness. Test the contribution/discovery flow on desktop/mobile with disposable fixtures and exact cleanup. Record local, pushed, CI, deployed and externally unverified evidence separately.
