# A continuous world of places

The user approved the chat description of one massive shared world containing many different places, then explicitly requested implementation, desktop/mobile support, push and merge. This extends the established canvas and `.21st/DESIGN.md` identity. It does not replace the product, rearrange originals, or introduce topic-based access rules.

## World geography

Add a small world atlas derived exclusively from the current snapshot. Seven geographic landmarks identify existing persisted creations: Waterloo, the mixtape, the large cat, the bread bus, the night train, the soup corner and the goose with a bag. A landmark exists only when actual nearby originals or pixels exist. Other occupied geographic cells become emergent places named from an actual original when possible. Signed coordinates and cells beyond these landmarks remain part of the same canvas. Each original/pixel belongs to one nearest eligible landmark or one deterministic geographic cell, so counts are exact and distant outliers do not stretch a place across the world.

World scenery is geographic wayfinding: faint irregular pastel contours and restrained dotted connections underneath the actual shared art. It does not add persisted pixels, inferred story relationships or synthetic contributions. World-distance place labels remain readable without replacing the actual papers/photos/pixels. Labels recede at close distance, hide during placing/painting/reading, and declutter against one another and screen controls. Travel uses the existing camera and reduced-motion behavior.

## Explore and make a place

Explore opens a compact World map panel and frames the real occupied world. Its miniature shows actual pixels, paper/photo positions and the current viewport. A list of places provides a keyboard/touch alternative; rows show factual original/open-build counts and a pixel emblem. Visiting a place closes the map, frames that actual neighborhood and retains its distinct geography. A small canvas location button returns to the map. No extra permanent dock action.

Start a place searches nearby open geographic cells within the write plane, avoiding existing originals and pixels. It frames the chosen ground and starts the existing invitation composer. The visitor writes the name/request and explicitly places/publishes it; opening this tool never publishes anything. That stored original makes the new place discoverable to another visitor and after reload. Nearby painting, notes, photos and independently authored build-on responses use the existing tools and persisted coordinates. Removing the last original does not hide surviving shared pixels. A parked draft or pixel preview is retained and must be resumed/settled rather than overwritten by this action.

Wander should distribute discovery across occupied places, preferring a different place with unseen originals before revisiting a dense one. It always opens a real original through the existing anchored preview; it never invents a story. Search/Ask and their exact-source return remain available, with global discovery across places. Legacy scene IDs remain storage compatibility metadata, not newly imposed categories.

## Engineering boundaries

Use small pure geographic helpers and a cached spatial index for persisted pixel rendering and map queries. Camera motion must query nearby buckets rather than scan every stored pixel. Keep peer cursors/previews in their existing temporary layers. This pilot keeps full world snapshots and current database/API contracts; the change does not claim population or network-scale capacity. No new dependency, font, illustration, anonymous activity, seed content or migration.

## Quality bar

The canvas stays the dominant surface. Extend the compact white/pastel pixel controls with a tiny original map emblem and geographic marks; no large title tiles, equal-card dashboard, modal onboarding or decorative slogan. Desktop and mobile show the same actual place at all three existing zoom levels. Mobile map actions remain at least44px high, sheets fit above the dock, long names wrap and the document never scrolls sideways. The area list stays usable when the miniature is too small for a particular place.

## Acceptance evidence

Prove empty-world honesty, unique assignment, negative/extreme coordinates, separated remote content, deterministic naming/removal, safe open-ground selection and place-aware unseen wandering. Prove indexed rendering excludes distant pixels while preserving previews and cursor redraw boundaries. Use two disposable real visitors to create a remote place, find it from the other browser, paint and leave linked text/photo responses, reload and revisit it. Verify draft preservation, sharing/search returns, keyboard travel,320px layout and actual mobile/desktop render captures. Run relevant existing browser suites, units/typecheck/build, fresh code/visual review, exact-commit CI and live deployment checks before completion.
