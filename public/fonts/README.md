# Memory Box fonts

Locally served Latin WOFF2 files used by `next/font/local`. Body and display files are variable fonts covering weights 400–700. IBM Plex Mono is regular 400. System fallbacks cover glyphs outside these subsets.

- Schibsted Grotesk: [official typeface](https://schibsted.com/about/schibsteds-visual-design/our-typeface/), [Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/schibstedgrotesk).
- Pixelify Sans: [Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/pixelifysans).
- IBM Plex Mono: [official font repository](https://github.com/IBM/plex), [Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).

WOFF2 files were obtained from the Google Fonts stylesheet for these exact families on 21 October 2026. SIL Open Font License texts are included beside the files. No runtime Google Fonts requests are needed.
